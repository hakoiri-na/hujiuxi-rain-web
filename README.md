# 雨结 · 汐间网页

nana「狐九汐」正文美化的公开网页产物。免费获取，禁止商业用途。

本仓库仅发布 `dist/reader.mount.html` 与使用说明、授权声明。网页在酒馆助手的消息页面中挂载，读取当前楼层的正文与 MVU，不写入游戏变量。没有原角色卡、示例开场、聊天记录、玩家存档、凭证或本地证据。

1.3.0 增加汐的小手机。只有「第一位联系人」事件记录为「已完成」才显示入口；聊天与表情包来自真实消息楼层。回复先放入酒馆输入框，保留已有草稿，由玩家亲自点击发送。表情包使用作者提供的两张图片，按需加载。手机消息格式与解锁规则由配套修订世界书规定。

原有无封面的通栏阅读布局、随日期变化的季节徽章、四种对话语言模式、红色祈愿绳和长纸御神签继续保留。

「文化注解」为可选设置：会联动当前角色绑定世界书里同名条目的启用开关，影响后续回复；关闭后已有注解只展示原词。只改变该条目的启用状态，保留世界书原始字段。开关状态来自实际世界书，读写失败会在页面内提示。

请使用作者交付的网页挂载正则。挂载链接固定到完整 Git 提交号；更新组件时一并更新提交号。需要 SillyTavern、酒馆助手以及原卡自带的 MVU / zod 脚本。
