# 雨结 · 汐间网页

nana「狐九汐」正文美化的公开网页产物。免费获取，禁止商业用途。

本仓库仅发布 `dist/reader.mount.html` 与使用说明、授权声明。网页在酒馆助手的消息页面中挂载，读取当前楼层的正文与 MVU，不写入游戏变量。没有原角色卡、示例开场、聊天记录、玩家存档、凭证或本地证据。

当前版本 1.4.1。手机首页不扫描聊天，LINE 只读取最近 60 楼；相册在进入时才分批整理当前聊天分支，同一次打开期间复用结果，聊天变化后重新读取。只更新游戏变量时保留正文和 CG 图片，切换主题、字号不重新创建手机记录。纸纹使用静态矢量小点，缘结绳在闲置时静止，只保留短暂悬停反馈。

随身手机从开场就可使用，可以按住前置摄像头拖动，双击居中。LINE 在「第一位联系人」事件完成后开放；相册从开始就能收录当前聊天分支中实际出现的 CG。回复先放入酒馆输入框，保留已有草稿，由玩家亲自点击发送。表情包与 CG 使用作者提供的图片，按需加载。

手机消息只使用 `<line>[发件人|信息内容|日期|时间]</line>`。表情内容写成 `【表情包：汐汐比心】` 或 `【表情包：汐汐哭哭】`；正文 CG 写成 `[cg|午后小憩]`。具体输出规则由配套修订世界书规定，旧版手机 JSON 和回复标记不再解析。

阅读设置先显示纸上四季，再显示一行四个对话语言选项；字号与行距预览包含中日双语。手机挂件和微风动效选项已移除。

原有无封面的通栏阅读布局、随日期变化的季节徽章、四种对话语言模式、红色祈愿绳和长纸御神签继续保留。

「文化注解」为可选设置：会联动当前角色绑定世界书里同名条目的启用开关，影响后续回复；关闭后已有注解只展示原词。只改变该条目的启用状态，保留世界书原始字段。开关状态来自实际世界书，读写失败会在页面内提示。

请使用作者交付的网页挂载正则。挂载链接固定到完整 Git 提交号；更新组件时一并更新提交号。需要 SillyTavern、酒馆助手以及原卡自带的 MVU / zod 脚本。
