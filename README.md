# 雨结 · 汐间网页

nana「狐九汐」正文美化的公开网页产物。免费获取，禁止商业用途。

本仓库仅发布 `dist/reader.mount.html` 与使用说明、授权声明。网页在酒馆助手的消息页面中挂载，读取当前楼层的正文与 MVU，不写入游戏变量。没有原角色卡、示例开场、聊天记录、玩家存档、凭证或本地证据。

请使用作者交付的网页挂载正则。挂载链接固定到完整 Git 提交号；更新组件时一并更新提交号。需要 SillyTavern、酒馆助手以及原卡自带的 MVU / zod 脚本。
